# Gym Booking

An Astro and Vue gym booking interface with an administration dashboard.
The customer records in `src/data/mock` are fictional demonstration data.

```sh
npm ci
npm run dev
```

Build with `npm run build`, or run the Docker setup with
`docker compose up --build` (http://localhost).

The administration page is a prototype, not an authenticated production
administration system. Keep real customer records out of the source tree.
